# PRECIS-2 inter-rater reliability

Reproducibility materials for a study evaluating agreement between two
reviewers applying the PRECIS-2 framework to 24 randomized controlled trials.
The repository documents data provenance, exclusions, verified corrections,
prespecified agreement definitions, analysis code, and machine-readable
results.

## Repository status

This repository is private pending co-author review. It should not be made
public or assigned a permanent data citation until the analysis, documentation,
and shareable data files have received final approval.

## Study dataset

- 24 randomized controlled trials
- 10 PRECIS-2 domains, including Comparator as Domain 10
- 2 independent reviewers: Aarian Bhakoo and Merrick Zwarenstein
- 237 paired trial-domain ratings
- 211 observations in analyses censoring codes 6 and 7

Scores 1-5 form the ordinal pragmatism scale. Code 6 represents Missing and
code 7 represents Not Applicable; these are treated as distinct nominal
categories rather than extensions of the ordinal scale.

## Analyses

Crude agreement and Krippendorff's alpha are calculated under four
prespecified definitions:

1. **Total:** exact matches constitute crude agreement; disagreement among
   scores 1-5 is ordinal, while nonidentical comparisons involving 6 or 7 have
   maximum disagreement.
2. **Range:** scores 1-5 within one point constitute crude agreement and have
   zero disagreement; codes 6 and 7 retain the Total rules.
3. **Censored:** observations containing code 6 or 7 for either reviewer are
   excluded.
4. **Bucketed:** scores are grouped as 1-2, 3, and 4-5; codes 6 and 7 remain
   separate nominal categories.

Secondary analyses report crude agreement by domain and each reviewer's mean
signed deviation from consensus using the common censored set.

## Reproduce the analysis

The main analysis was run using R 4.3.1. Open `precis2-irr.Rproj` in RStudio,
then run:

```r
source("run-analysis.R")
```

The script checks required packages and stops if the data structure or accepted
verification totals change. It creates:

- `outputs/reports/precis2-irr-analysis.pdf`
- `outputs/results/global-crude-agreement.csv`
- `outputs/results/domain-crude-agreement.csv`
- `outputs/results/krippendorff-alpha.csv`
- `outputs/results/reviewer-deviation-from-consensus.csv`
- `outputs/results/session-info.txt`

The Krippendorff's alpha implementation in the main report is preserved from
the statistician-reviewed script. See
`documentation/step-2-change-crosswalk.md` for an explicit change record.

## Provenance and corrections

The finalized tables use domain-major ordering. Thompson (2000B) Domains 7-9
are excluded. Three independently verified corrections are applied only to the
derived ratings table and are recorded in
`data/derived/verified_corrections.csv`. Source files in `archive/` remain
unchanged. The manuscript is not modified by this repository workflow.
The local `archive/` directory is excluded from Git history so that manuscript
drafts and unreviewed workbook content cannot persist when the repository is
eventually made public.

## Data availability and citation

Before public release, the approved repository version should be archived in a
research-data repository that issues a persistent identifier, such as Zenodo.
That DOI should replace the placeholders in the manuscript data-availability
statement and repository citation. GitHub is used for version control; the
archived release will serve as the citable dataset and code record.
